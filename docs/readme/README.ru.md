## Что это такое

В целом если вы сами хоть раз ставили сырой композитор на Wayland вам не стоит объяснять "зачем ему шелл". Но объяснить работу я обязан


```
ваши приложения
   ↓
Illogical-mango   панель, док, сайдбары, обзор, уведомления, настройки, локскрин
   ↓
Quickshell        QML-рантайм для Wayland-шеллов
   ↓
MangoWM           окна и отрисовка
   ↓
Wayland → GPU
```

**Чем отличается от прочих конфигов Quickshell:**

- **Два полноценных семейства панелей в одной установке.** Material ii (плавающая панель,
  сайдбары, док) и Waffle (нижний таскбар, меню «Пуск», центр действий). Это не темы
  поверх одних и тех же виджетов — это отдельные деревья панелей со своими системами
  токенов, переключаются на лету по <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd>.
- **Тематизация всей системы, а не только шелла.** Одни обои задают палитру Material You,
  которая выписывается в GTK3/4, Qt, десять терминалов и TUI-утилит, Firefox, Discord,
  Spicetify, Steam и SDDM.
- **Настраивается без правки кода.** Всё — настройка в GUI поверх одного `config.json`.
  Трогать QML, чтобы поменять вид или поведение, не нужно никогда.
- **Настоящий путь установки и обновления.** `./setup` берёт на себя зависимости и
  системный конфиг; `inir update` делает pull, прогоняет миграции схемы, сохраняет ваши
  изменения и умеет откатываться.

**Происхождение.** [illogical-impulse от end-4](https://github.com/end-4/dots-hyprland)
(дотфайлы для Hyprland) → [iNiR от snowarch](https://github.com/snowarch/iNiR) (переписан
под niri) → это, портированное на MangoWM. CLI, пути конфигов и внутренности по-прежнему
называются `inir`: переименование сломало бы все пути обновления, поэтому имя осталось.
Почему не скопировать именно end-4? Логика тут простая - перенесённый раз проект перенести проще. 
В аналогию возьму Void linux. Если на него установить systemd, то он будет спокойно работать.
Если взять Arch linux и оторвать от SystemD, то нужно будет менять почти всю пакетную базу


## Композитор

Сделан под [MangoWM](https://github.com/DreamMaoMao/mango) и тестируется только на нём.

Шелл общается с mango через его IPC-сокет по `$MANGO_INSTANCE_SIGNATURE`, который на
каждое изменение присылает полный снимок сессии. mango устроен в духе dwm — теги, а не
список рабочих столов, — поэтому `MangoService` отображает пары `(монитор, индекс тега)`
на ту же модель рабочих столов, которую уже ожидают панель, док, обзор и полоса рабочих
столов, и эти модули работают без изменений.

Конфигурация принципиально недеструктивна. mango читает ровно один файл
(`~/.config/mango/config.conf`) и ничего не мержит, поэтому установщик никогда не
переписывает ваш конфиг композитора. Он кладёт клавиши и автозапуск шелла в
`~/.config/mango/inir.conf` и дописывает одну строку `source-optional=` со ссылкой на
него, не трогая ваше управление окнами. Автозапуск — строка `exec-once=inir run --daemon`
в этом файле, а не systemd-юнит.

> [!NOTE]
> **Код niri и Hyprland всё ещё лежит в дереве.** `NiriService.qml`, `HyprlandData.qml` и
> ветки `isNiri` / `isHyprland` остались от upstream и по-прежнему собираются. Они
> унаследованы, но не поддерживаются: ничего здесь не тестируется на этих композиторах и
> ничего под них не сопровождается. Нужен niri — берите
> [оригинальный iNiR](https://github.com/snowarch/iNiR).

## Возможности

**Два семейства панелей**, переключаются на лету по <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd>:

- **Material ii** — плавающая панель, сайдбары, док и 8 визуальных стилей (Material,
  Cards, Aurora, iNiR, Angel, Regalia, ZZZ, Cookie Shapes)
- **Waffle** — таскбар в духе Windows 11, меню «Пуск», центр действий, центр уведомлений

**Автоматическая тематизация.** Выбираете обои — и за ними идёт вся система: цвета
Material You для шелла раскатываются на GTK3/4, Qt, терминалы, Firefox, Discord,
Spicetify, Steam и SDDM. В комплекте пресеты Regalia, Gruvbox, Catppuccin и Rosé Pine, или
соберите свой.

## Быстрый старт (установщик будет другой в будущем)

```bash
git clone https://github.com/ItzWithTails/Illogical-mango.git
cd Illogical-mango
./setup install       # интерактивно, спрашивает перед каждым шагом
./setup install -y    # автоматически, без вопросов
```

Установщик разбирается с зависимостями, системным конфигом и тематизацией. Клавиши шелла
он пишет в `~/.config/mango/inir.conf` и подключает их к вашему существующему конфигу
mango, не трогая управление окнами. Перезапустите mango или выполните
`mmsg dispatch reload_config`.

```bash
inir run                        # запустить шелл
inir settings                   # открыть GUI настроек
inir logs                       # посмотреть логи
inir doctor                     # автодиагностика и починка
inir update                     # pull + миграции + перезапуск
```

Другие точки входа:

```bash
./setup                 # TUI-меню, выбираете что нужно
./setup install --skip-mango    # вообще не трогать конфиг mango
sudo make install       # системная установка вместо домашней
./setup rollback        # откатить последнее обновление
```

**Дистрибутивы.** Arch — основная цель и лучше всего оттестирован. Для Debian и Fedora конечно порт есть... на ваш страх и риск, тестирования на них не было.

## Клавиши

Ставятся из `defaults/mango/config.conf`:

| Клавиша | Действие |
|-----|--------|
| <kbd>Super</kbd> + <kbd>Space</kbd> | Обзор: поиск приложений, навигация по тегам |
| <kbd>Super</kbd> + <kbd>V</kbd> | История буфера обмена |
| <kbd>Super</kbd> + <kbd>P</kbd> | Левый сайдбар |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> | Правый сайдбар |
| <kbd>Super</kbd> + <kbd>D</kbd> | Дашборд |
| <kbd>Super</kbd> + <kbd>,</kbd> | Настройки |
| <kbd>Super</kbd> + <kbd>/</kbd> | Шпаргалка |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> | Сменить семейство панелей |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Скриншот области |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | OCR области |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> | Запись области |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | Обратный поиск по области |
| <kbd>Super</kbd> + <kbd>L</kbd> | Блокировка |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Delete</kbd> | Экран сессии |

Клавиши управления окнами — ваши, шелл их не определяет. Полный справочник:
[Клавиши](../KEYBINDS.md).

## Решение проблем

```bash
inir logs                       # свежие логи рантайма
inir restart                    # перезапустить активный рантайм
inir repair                     # doctor + перезапуск + отфильтрованная проверка логов
inir doctor                     # автодиагностика и починка типичных проблем
./setup rollback                # откатить последнее обновление
claude "помоги пожалуйста"      # если вы не хотите разбираться сами. нуачё, надо же чтобы он свои 20$ отработал
```

Загляните в [Ограничения](../LIMITATIONS.md), чтобы посмеятся.
